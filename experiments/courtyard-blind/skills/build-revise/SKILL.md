name: build-revise
description: Build and revise this packet's assets using native inspection and scoped checkpoints.
---

Start each new task with an expected missing-deliverable check; do not damage existing work to manufacture a failure. For an edit, inspect the native baseline and declared change first. Resolve silhouette, proportions, modular joins and sightlines before detail. Viewport/render appearance can reveal defects that numerical dimensions cannot.

Use unique instance IDs and shared asset/material IDs. Duplicated objects need fresh placement identities; linked geometry edits affect every user. Decide intentionally between shared edits and local variants. Preserve unrelated lighting and shared material definitions while working on an asset.

Write intended changes to an append-only task log under output/ before native mutation, then record the observed result. Do not retry an unresolved write without inspecting native effects. Save accepted task boundaries to new .blend filenames. Inspect properties with native Blender APIs; use supplied measurement helpers only when present in this packet. Never infer topology or artistic correctness from limited measurements.
