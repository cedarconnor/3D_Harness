# Everyday workflow and craft increment — October 5, 2026

Version 0.4.0 implements an ordinary-project entry point above the existing continuity store and MCP, plus four focused craft skills. It is a bounded usability and reliability increment authorized after the earlier comparisons. It does not complete the interrupted realism comparison or establish an aesthetic advantage.

## Delivered

- Project entry skill `dcc-harness`, routing start/resume/review/revision and loading craft skills only when relevant.
- CLI `start`, `resume`, `review`, `begin-edit`, `finish-edit` alongside unchanged legacy commands.
- Compact verified resume packets with retained decisions, current handoff, focused material/mesh users, recent accepted/rejected edits and explicit unresolved state.
- Exclusive workflow metadata locks, retained script/contract reservations, parent/saved-file/observation checks, and explicit reconciliation. No timeout-driven write replay or automatic stale-lock deletion.
- Four craft skills: architecture, materials, environment assembly and lighting review. Two small executable recipes support rectangular wall openings and guarded shared-material scalar edits.
- Runtime wheel `dist/dcc_harness-0.4.0-py3-none-any.whl`; project skills remain in `.agents/skills/`, separate from the wheel. See [everyday usage](EVERYDAY_WORKFLOW.md) and [craft boundaries](CRAFT_SKILLS.md).

## Practical limits and next work

Reservations control cooperating workflow callers, not arbitrary MCP, legacy API or manual editor writes. Native execution and metadata publication are not one transaction. Partial records or stale locks deliberately require inspection. Producer observations are trusted evidence claims; hashes do not authenticate truth. No agent scheduler, credential management, quota bypass or client marketplace installer was added.

The new skills have validated structure and executed bounded recipes; fresh-agent behavioral validation and artistic benefit remain unproven. In particular, environment assembly and lighting need sustained production use. The current continuity checker cannot express a world-setting change or creation of new lights; the lighting skill identifies that boundary before dispatch.

The next useful creative pilot is a separate production branch of the approved shed direction: develop connected ground/boundary/planting zones, then revise architecture and materials across fresh contexts while measuring unintended changes and artist repair time. Keep the old studies and their failures intact. Do not count engineering fixture passes as successful creative trials.
